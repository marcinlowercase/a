# keyboard shortcuts

| shortcut | action |
| --- | --- |
| `ctrl + l` | focus and select url, or edit current url |
| `ctrl + shift + c` | copy current url |
| `ctrl + r` | refresh current tab |
| `ctrl + t` | open new tab and focus url bar |
| `ctrl + enter` | open url bar input in new tab |
| `esc` | dismiss url bar |
