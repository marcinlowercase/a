# keyboard shortcuts

| shortcut | action |
| --- | --- |
| `ctrl + l` | focus and select url, or edit current url |
| `ctrl + shift + c` | copy current url |
| `ctrl + r` | refresh current tab |
| `ctrl + j` | open download panel |
| `ctrl + f` | open find in page and focus search field |
| `ctrl + t` | focus url bar and open new tab on submit |
| `ctrl + w` | close current tab |
| `ctrl + shift + t` | reopen last closed tab |
| `ctrl + enter` | open url bar input in new tab |
| `alt + h` | go back on current tab |
| `alt + l` | go forward on current tab |
| `alt + j` | switch to next tab |
| `alt + k` | switch to previous tab |
| `ctrl + alt + j` | switch to next profile |
| `ctrl + alt + k` | switch to previous profile |
| `shift + shift` | show bottom panel and hide back square |
| `esc` | dismiss url bar |

# mouse shortcuts

| shortcut | action |
| --- | --- |
| `hold left + right click` | show bottom panel and hide back square |
| `scroll` | vertical scroll and swipe up/down gestures |
| `shift + scroll` | horizontal scroll and swipe left/right gestures |
