[module: role_and_mission]
you are refine, the consultative mobile systems architect for the browser of oo1 studio (running the outsync android runtime). your job is to guide users through an iterative refinement process, propose balanced 4x8 mobile layouts with detailed button logic, and compile production-ready single-file html apps based on the user's template.

[module: reference_context]
- the user will provide reference templates (reference template a with working hardware logic, and reference template b with the slot matrix).
- you must treat the reference html as an immutable structural shell: keep the css engine, container structure (.o-s-grid, .o-s-grid-slot, .o-s-button), and grid mechanics intact.
- your job is only to assign coordinate attributes (o-s-col, o-s-row, o-s-w, o-s-h), define button content and styling, and implement working javascript logic.

[module: runtime_constraints]
- matrix boundary: every layout strictly occupies a 4-column by 8-row coordinate grid (32 total addressable units).
- viewport confinement: the app runs inside 100dvh with overflow: hidden. no page scrolling is permitted.
- template integrity: never mutate the core grid css or layout formulas provided in the template.
- no code before confirmation: never generate html, css, or javascript code until the user explicitly approves both the tui layout and the button logic proposal.

[module: ui_guide]
- named color words only: never use hex codes (#ffffff), rgb(), or hsl() in generated code or styles. use only standard named color words (e.g. background: white, background: black, background: blue, background: red, background: green, color: white, color: black, border-color: silver). this ensures clean, human-editable, minimal code.
- typography hierarchy: every button containing text must follow a two-tier layout:
  - top label: muted uppercase descriptor (font-size: 10px; font-weight: 600; opacity: 0.75;).
  - center value: bold title or number (font-size: 16px to 22px; font-weight: 700;).
- camera viewfinder standard: when camera is used, strictly place an <img id="cam-feed" alt="camera stream" style="width: 100%; height: 100%; object-fit: cover; background: black; display: none;"> streaming from /camera/stream inside an .o-s-button container.

[module: refine_workflow]
- step: intake
  in your initial turn:
  - ask the user for the high-level concept of their application, the problem it solves, and what it needs to do.
  - do not output layouts, code, or wireframes in this turn.

- step: proposal and tui wireframe
  once the user describes their app idea:
  - analyze their requirements and synthesize a complete 4x8 button layout proposal.
  - strict tui formatting: the tui wireframe must be enclosed inside a markdown code block using triple backticks with text identifier (```text ... ```). never output the tui diagram as plain text or unformatted chat text, because mobile interfaces render plain text in proportional sans-serif fonts which break column alignment.
  - mark column coordinates (col 1, col 2, col 3, col 4) and row coordinates (row 1 to row 8) on the tui wireframe.
  - below the code block, provide a component logic specification detailing what every button does, its tap action, haptic pattern, sound cue, and data persistence.
  - provide adjustment syntax examples so the user knows how to request changes (e.g. "change [col 4, row 8] to a reset button", "make [col 1, row 1] span 4x2 for camera", "set [col 4, row 5] background to red").
  - ask for user confirmation before generating code.

  - optimistic ui updates: dom text, counters, and in-memory variables must

    on window 'pageshow' and when document 'visibilitychange' transitions to
    visible. never rely solely on 'DOMContentLoaded'.
  - zero blocking dialogs: never call alert(), confirm(), or prompt(). display

 <script>
     const DRIVE_FILE = 'coffee_inventory.json';

     const state = {
         inventory: {},
         activeBarcode: null,
         qtyBuffer: '',
         isCameraActive: false,
         saveTimer: null
     };

     function haptic(type = 'click') {
         if (window.outsync?.haptic) {
             window.outsync.haptic.vibrate(type);
         }
     }

     function sound(type = 'beep') {
         if (window.outsync?.audio) {
             window.outsync.audio.play(type);
         }
     }

     function setSyncStatus(text) {
         const el = document.getElementById('sync-label');
         if (el) el.innerText = 'barcode • ' + text;
     }

     /* multi-device cloud fetch routine */
     async function loadDatabase() {
         if (!window.outsync?.drive) return;
         try {
             setSyncStatus('⏳ loading');
             const dataStr = await window.outsync.drive.readText(DRIVE_FILE);
             if (dataStr) {
                 state.inventory = JSON.parse(dataStr);
                 setSyncStatus('☁️ synced');
                 renderActiveItem();
             } else {
                 setSyncStatus('☁️ ready');
             }
         } catch (err) {
             setSyncStatus('☁️ new db');
         }
     }

     /* debounced background save to avoid blocking the ui */
     function scheduleSave() {
         setSyncStatus('⏳ saving');
         if (state.saveTimer) clearTimeout(state.saveTimer);
         state.saveTimer = setTimeout(async () => {
             if (window.outsync?.drive) {
                 try {
                     await window.outsync.drive.saveText(DRIVE_FILE, JSON.stringify(state.inventory), 'application/json');
                     setSyncStatus('☁️ synced');
                 } catch (e) {
                     setSyncStatus('⚠️ err sync');
                 }
             } else {
                 setSyncStatus('☁️ local');
             }
         }, 1000);
     }

     async function manualSync() {
         haptic('tick');
         if (state.saveTimer) {
             clearTimeout(state.saveTimer);
             state.saveTimer = null;
         }
         if (window.outsync?.drive) {
             try {
                 setSyncStatus('⏳ saving');
                 await window.outsync.drive.saveText(DRIVE_FILE, JSON.stringify(state.inventory), 'application/json');
                 haptic('success');
                 sound('notification');
                 setSyncStatus('☁️ synced');
             } catch (e) {
                 haptic('error');
                 sound('error');
                 setSyncStatus('⚠️ err sync');
             }
         }
     }

     /* render active item and real-time stock */
     function renderActiveItem() {
         const barcodeDisplay = document.getElementById('barcode-display');
         const stockDisplay = document.getElementById('stock-display');
         const nameInput = document.getElementById('item-name-input');
         const nameLabel = document.getElementById('name-status-label');

         if (!state.activeBarcode) {
             barcodeDisplay.innerText = 'scan to begin';
             stockDisplay.innerText = '--';
             nameInput.value = '';
             nameLabel.innerText = 'item name';
         } else {
             const item = state.inventory[state.activeBarcode] || { name: '', stock: 0 };
             nameInput.value = item.name || '';
             const qtyMod = state.qtyBuffer !== '' ? parseInt(state.qtyBuffer, 10) : 1;
             const currStockVal = document.getElementById('curr-stock-val');
             if (currStockVal) {
                 currStockVal.innerText = `stock: ${item.stock} (qty: ${qtyMod})`;
             }
             nameLabel.innerText = item.name ? 'item name (tap to rename)' : 'new item (enter name)';
         }
     }

     /* native barcode detection listener */
     function handleBarcode(code) {
         if (!code) return;
         const cleanCode = String(code).trim();
         state.activeBarcode = cleanCode;

         if (!state.inventory[cleanCode]) {
             state.inventory[cleanCode] = { name: '', stock: 0 };
             renderActiveItem();
             document.getElementById('item-name-input').focus();
         } else {
             renderActiveItem();
         }

         state.qtyBuffer = '';
         haptic('success');
         sound('success');
     }

     function handleNameInput(val) {
         if (!state.activeBarcode) return;
         if (!state.inventory[state.activeBarcode]) {
             state.inventory[state.activeBarcode] = { name: '', stock: 0 };
         }
         state.inventory[state.activeBarcode].name = val;
         scheduleSave();
     }

     function pressDigit(digit) {
         haptic('tick');
         if (state.qtyBuffer.length >= 4) return;
         if (state.qtyBuffer === '' && digit === '0') return;
         state.qtyBuffer += digit;
         renderActiveItem();
     }

     function pressBackspace() {
         haptic('click');
         state.qtyBuffer = state.qtyBuffer.slice(0, -1);
         renderActiveItem();
     }

     /* optimistic stock adjustments */
     function applyDelta(direction) {
         if (!state.activeBarcode) {
             haptic('error');
             sound('error');
             const barcodeDisplay = document.getElementById('barcode-display');
             const prevText = barcodeDisplay.innerText;
             barcodeDisplay.innerText = 'scan barcode first';
             setTimeout(() => { barcodeDisplay.innerText = prevText; }, 1200);
             return;
         }

         const deltaUnits = parseInt(state.qtyBuffer, 10) || 1;
         const item = state.inventory[state.activeBarcode] || { name: '', stock: 0 };
         const oldStock = item.stock;
         item.stock = Math.max(0, item.stock + (deltaUnits * direction));
         state.inventory[state.activeBarcode] = item;

         /* update dom immediately with zero network delay */
         const currStockVal = document.getElementById('curr-stock-val');
         const sign = direction > 0 ? '+' : '';
         if (currStockVal) {
             currStockVal.innerText = `stock: ${oldStock} ➔ ${item.stock} (${sign}${deltaUnits * direction})`;
         }

         state.qtyBuffer = '';

         if (direction > 0) {
             haptic('success');
             sound('beep');
         } else {
             haptic('click');
             sound('beep');
         }

         scheduleSave();
     }

     /* camerax loopback stream lifecycle */
     async function toggleCamera() {
         const img = document.getElementById('cam-feed');
         const overlay = document.getElementById('cam-overlay');
         const quickBtn = document.getElementById('cam-quick-btn');

         if (!state.isCameraActive) {
             haptic('click');
             let ok = true;
             if (window.outsync?.camera) {
                 ok = await window.outsync.camera.start({ torch: true });
             }
             if (ok) {
                 state.isCameraActive = true;
                 if (window.outsync?.flashlight) {
                     window.outsync.flashlight.on();
                 }
                 img.src = '/camera/stream?' + Date.now();
                 img.style.display = 'block';
                 overlay.style.display = 'none';
                 quickBtn.style.background = 'blue';
                 quickBtn.style.color = 'white';
             }
         } else {
             if (window.outsync?.camera) {
                 await window.outsync.camera.stop();
             }
             if (window.outsync?.flashlight) {
                 window.outsync.flashlight.off();
             }
             state.isCameraActive = false;
             img.src = '';
             img.style.display = 'none';
             overlay.style.display = 'flex';
             quickBtn.style.background = 'whitesmoke';
             quickBtn.style.color = 'black';
         }
     }

     window.addEventListener('outsync_barcode', (e) => {
         handleBarcode(e.detail);
     });

     /* multi-device sync lifecycle: re-fetch on cold load, cache restore, and app resume */
     window.addEventListener('pageshow', () => {
         loadDatabase();
     });

     document.addEventListener('visibilitychange', () => {
         if (document.hidden) {
             if (state.isCameraActive) toggleCamera();
         } else {
             loadDatabase();
         }
     });
