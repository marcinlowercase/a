1. outsync.css Design Tokens & Reactive Layer Math

Include the hosted stylesheet inside your document <head>: <link rel="stylesheet" href="https://assets.oo1.studio/outsync.css">. When outsync is enabled in browser settings, the WebExtension injects live host device metrics onto :root at document_start and scales them proportionally when desktop mode is active.

Base Host Constants (Injected onto :root)

CSS Variable Default / Unit Description
--device-corner-radius 28px Physical device screen corner radius (Layer 0)
--base-radius 28px Fallback minimum radius floor for nested layers (≥ 1)
--padding 8px Base spacing unit matching the host browser UI grid
--single-line-height 100px Base single-row interactive control height
--max-list-height 2 (multiplier) Maximum stacked item multiplier for container sizing
--highlight-color blue (CSS color) Active profile accent or dynamic Material You primary color
--on-highlight / --off-highlight white / black Foreground contrast colors for active and inactive controls
--animation-speed 300ms Base transition duration configured by the user
--layer 0 (integer) Nesting depth index set per element to drive concentric scaling

Reactive Layer Computed Variables (Calculated Per Element)

By setting --layer: 1, --layer: 2, etc. on nested child containers, outsync.css automatically computes concentric corner radii, inner heights, and snappier child animations:

Computed Variable Reactive Formula
--layer-corner-radius max(0px, max(deviceCornerRadius, baseRadius * min(1, layer)) - (padding * layer))
--layer-min-height singleLineHeight - (padding * layer * 2)
--layer-height max(layerCornerRadius * 2, layerMinHeight)
--layer-max-container-size (layerHeight * maxListHeight) + (padding * (maxListHeight + 1))
--layer-animation-speed max(0ms, animationSpeed - (50ms * layer))

2. window.outsync Native Bridge API

All native hardware and storage capabilities are exposed asynchronously on window.outsync through GeckoView's sandboxed WebExtension IPC bridge.

Haptics & Audio

Method Parameters Returns / Notes
outsync.haptic.vibrate(type) 'tick' | 'click' | 'heavy' | 'double_click' | 'success' | 'error' | 'rise' | 'celebration' | 'warning' Promise<'SUCCESS' | 'FAIL'> — Android 11+ composition primitives with Android 10 waveform fallbacks
outsync.audio.play(sound) 'beep' | 'success' | 'error' | 'notification' Promise<'SUCCESS' | 'FAIL'> — Low-latency ToneGenerator cues and default notification chime

Camera, ML Kit Barcode Scanner & Flashlight

Method / Event Parameters Returns / Notes
outsync.camera.start(options) { torch?: boolean } Promise<boolean> — Starts CameraX loopback MJPEG stream at /camera/stream
outsync.camera.stop() None Promise<boolean> — Stops camera session and releases hardware
window 'outsync_barcode' CustomEvent (e.detail) Fires continuously with decoded barcode string from on-device ML Kit
outsync.flashlight.toggle(enabled?) Optional boolean Promise<'ON' | 'OFF' | 'NO_FLASH_HARDWARE' | 'ERROR'>
outsync.flashlight.on() / .off() None Explicit torch control (works whether camera is running or stopped)
outsync.flashlight.getMaxStrength() None Promise<number> — Max torch strength level on Android 13+
outsync.flashlight.setStrength(level) number (0 turns off) Promise<'ON' | 'OFF' | 'ERROR'>

Google Drive (BYOS) & Local Device Storage

Method Parameters Returns / Notes
outsync.drive.saveText(filename, content, mimeType) Strings (default mime 'application/json') Promise<'SUCCESS' | ErrorString> — Saves inside app-isolated Google Drive folder
outsync.drive.readText(filename) string Promise<string> — Returns file contents or error string
outsync.drive.listFiles() None Promise<Array> — Lists file metadata objects inside app folder
outsync.drive.deleteFile(filename) string Promise<'SUCCESS' | ErrorString>
outsync.storage.save(filename, base64Data, mimeType, folder) folder: 'DOWNLOADS' | 'PICTURES' Promise<'SUCCESS'> (rejects on permission denial or write error)

Device State

Method Returns Notes
outsync.device.isScreenOn() Promise<boolean> Checks Android PowerManager.isInteractive
outsync.device.isConnected() Promise<boolean> Checks validated internet capability
All drive and device methods also expose snake_case aliases (e.g. save_text, read_text, list_files, delete_file, is_screen_on, is_connected).

Standard Drive Error Strings: ERROR_PERMISSION_DENIED, ERROR_NOT_AUTHENTICATED, ERROR_NOT_FOUND, ERROR_SAVING, ERROR_DELETING.

3. Local-First & Multi-Device Sync Pattern

To keep mobile interfaces instant without blocking on network requests, follow the optimistic-UI plus 1000ms debounced Google Drive BYOS pattern: 

const DRIVE_FILE = 'app_data.json';
let saveTimer = null;
let state = {};

async function loadFromDrive() {
  if (!window.outsync?.drive) return;
  try {
    const raw = await window.outsync.drive.readText(DRIVE_FILE);
    if (raw && !raw.startsWith('ERROR_')) {
      state = JSON.parse(raw);
      render();
    }
  } catch (_) {}
}

function scheduleSave() {
  if (saveTimer) clearTimeout(saveTimer);
  saveTimer = setTimeout(async () => {
    if (window.outsync?.drive) {
      await window.outsync.drive.saveText(DRIVE_FILE, JSON.stringify(state), 'application/json');
    }
  }, 1000);
}

window.addEventListener('pageshow', loadFromDrive);
document.addEventListener('visibilitychange', () => {
  if (!document.hidden) loadFromDrive();
});

4. Security Sandbox & Local Execution

Every external and local web application executes inside GeckoView's contextual permission sandbox:

Resource Sandbox Boundary
Local HTML Apps Served via isolated loopback virtual scheme local://apps/<slug>/index.html (drafts under local://draft); root filesystem paths are never exposed
Camera & Scanner Gated by per-domain site permission prompt + Android OS CAMERA runtime permission
Google Drive (BYOS) Gated by per-domain Drive access prompt; every app is strictly isolated to its own partitioned folder via DRIVE_FILE
Device File Saving Gated by per-domain storage permission prompt; writes only scoped MediaStore entries in public Downloads or Pictures

5. 4x8 Mobile Matrix Shell & Minimal Starter

Single-file applications compiled by the refine AI Prompt SDK link outsync.css for hardware-reactive CSS tokens and lock UI controls into an inline, non-scrolling 4-column by 8-row matrix inside 100dvh (preventing layout shifts on low-end devices).

Shell Attribute / Class Allowed Values Purpose
.o-s-grid / .o-s-grid-slot Container & Slot Fixed 4×8 non-scrolling layout grid inside 100dvh
o-s-col / o-s-row 1..4 (col), 1..8 (row) 1-indexed starting coordinates for a grid slot
o-s-w / o-s-h 1..4 (width), 1..8 (height) Column and row span inside the 4×8 matrix
.o-s-button dark, named CSS colors Interactive tile scaled using --layer-corner-radius

Complete Minimal Starter Boilerplate (Single-File)

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
  <title>Minimal outsync App</title>
  <link rel="stylesheet" href="https://assets.oo1.studio/outsync.css">
  <style>
    * { box-sizing: border-box; margin: 0; padding: 0; }
    body { height: 100dvh; background: black; color: white; padding: var(--padding); font-family: sans-serif; }
    .o-s-grid { display: grid; grid-template-columns: repeat(4, 1fr); grid-template-rows: repeat(8, 1fr); gap: var(--padding); height: 100%; }
    .o-s-grid-slot { --layer: 1; display: flex; }
    .o-s-button { width: 100%; border-radius: var(--layer-corner-radius); border: none; font-weight: bold; font-size: 16px; cursor: pointer; }
  </style>
</head>
<body>
  <main class="o-s-grid">
    <div class="o-s-grid-slot" style="grid-column: 1 / span 4; grid-row: 7 / span 2;">
      <button class="o-s-button" style="background: var(--highlight-color); color: var(--on-highlight);" onclick="triggerAction()">
        TAP TO TEST HAPTIC & BEEP
      </button>
    </div>
  </main>
  <script>
    async function triggerAction() {
      if (window.outsync) {
        await window.outsync.haptic.vibrate('success');
        await window.outsync.audio.play('beep');
      }
    }
  </script>
</body>
</html>
